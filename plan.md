# Anchor Health Wallet - Website Implementation Plan

## 1. Visual Identity & Brand System
- **Colors**: Primary: Teal-600 (#0D9488), Secondary: Slate-900 (#0F172A), Accent: Blue-500 (#3B82F6). Background: White/Slate-50.
- **Typography**: Sans-serif (Inter/Geist) - clean, modern, high-readability.
- **Style**: Minimalism + Glassmorphism for AI elements. Soft shadows, rounded corners (2xl/3xl), subtle gradients.

## 2. Component Architecture
- `Navbar`: Sticky, glassmorphism, responsive menu.
- `Hero`: Two-column layout with bold headline, AI badge, and high-fidelity dashboard mockup.
- `Problem`: 3-card grid with high-impact stats and localized healthcare context.
- `Solution`: Mobile app preview paired with key value propositions and "Smart Financing" messaging.
- `Features`: 6-card grid with icons and hover-driven detail expansion.
- `HowItWorks`: Horizontal stepper with clear 1-4 progression and visual connectors.
- `AILayer`: Dark-themed high-tech section showing predictive analytics and risk scoring mockups.
- `Impact`: 4-column metric grid with "odometer" style stats.
- `Partners`: Marquee or flex-grid of grayscale partner logos.
- `Founder`: Professional spotlight on Dr. Samuel Tesfaye with vision statement.
- `CTA`: Large, high-conversion section with clear next steps.
- `Footer`: Clean, multi-column with Ethiopian headquarters and legal links.

## 3. Tech Stack
- **React 19**: Functional components, modern hooks.
- **Tailwind CSS**: Utility-first, responsive, custom theme tokens.
- **Framer Motion**: Scroll-triggered animations, entrance transitions.
- **Lucide React**: Consistent icon set.
- **Shadcn UI**: Base components (Button, Card, Badge, etc.).

## 4. Key Improvements (Refinement Phase)
- Implement scroll-linked animations for the workflow sections.
- Enhance the AI dashboard with pulsing "data points" overlay.
- Add subtle "Tilet" (Ethiopian pattern) inspired motifs in dividers or backgrounds.
- Ensure all images use the newly generated high-fidelity assets.
